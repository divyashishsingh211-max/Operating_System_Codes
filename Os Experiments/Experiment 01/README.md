# Experiment 1 — Linux System Administration & Process Management

**Aim:** To practise basic Linux commands for file management and process management.

## File & Directory Commands

| Command | Meaning | Use |
| --- | --- | --- |
| `pwd` | Print Working Directory | Shows the current directory path |
| `ls` | List | Lists files and directories |
| `tree` | Directory tree | Displays folders in a tree structure |
| `cd` | Change Directory | Moves to another directory |
| `mkdir` | Make Directory | Creates a new directory |
| `touch` | Touch | Creates an empty file or updates its timestamp |
| `cat` | Concatenate | Displays the contents of a file |
| `echo` | Echo | Prints text or writes it to a file |
| `clear` | Clear | Clears the terminal screen |
| `history` | History | Shows previously executed commands |

## Process Management Commands

| Command | Meaning | Use |
| --- | --- | --- |
| `sleep` | Sleep | Pauses for a given number of seconds |
| `jobs` | Jobs | Lists background and stopped jobs of the current shell |
| `ps` | Process Status | Shows running processes |
| `ps -o` | Process Status with Output format | Displays selected columns, e.g. `pid,ni,cmd` |
| `kill` | Kill | Sends a signal to stop a process by PID or job ID |
